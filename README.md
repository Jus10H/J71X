# Vegansmegan

A nutrition research and meal planning project for an optimized plant-based meal replacement shake based on longevity research and whole-food nutrition principles.

## Protocol Versions

| Document | Use Case | Fat | Cooking |
|----------|----------|-----|---------|
| `The_Complete_Meal_Replacement_Protocol.md` | Standard daily use | 48g (21%) | Required |
| `The_Complete_Meal_Replacement_Protocol_LOW_FAT.md` | Heart health / Esselstyn-style | 25g (11%) | Required |
| `The_Complete_Meal_Replacement_Protocol_NO_COOK.md` | Busy days | 46g (20%) | None |

## LowCookLowFat

The `LowCookLowFat/` folder contains the active working protocol:

- **Shopping List** - Sourced brands with third-party testing
- **Prep Guide: Capsules** - Weekly batch fill instructions for spice capsules
- **Prep Guide: Shake** - Daily blending instructions
- **Prep Guide: Chewables** - Optimal cooking methods for each vegetable (research-backed)

## Research

- `report1/` through `report4/` - Research iterations and formulation development
